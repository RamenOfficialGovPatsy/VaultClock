# 🕰️🔐 VaultClock — плагин Obsidian

Плагин для Obsidian, который считает время, проведённое в приложении, и показывает четыре метрики: общее время, за сегодня, за 7 дней и за 30 дней. Тихо, без графиков и лишнего UI — только цифры в статус-баре и простая панель статистики 👻

## ✨ Возможности

- ⏱️ Учёт всего времени, пока Obsidian запущен — без пауз, без idle-детекта, без учёта фокуса
- 📊 Четыре метрики: общее время, за сегодня, за 7 дней, за 30 дней
- 📌 Элемент в статус-баре: `⏱️ 2ч 15м` — время за сегодня, обновляется каждые 30 секунд
- 🖱️ Клик по статус-бару открывает панель статистики
- 🧭 Команды в палитре: «Открыть статистику» и «Сбросить статистику»
- 💾 Локальное хранение в `data.json`, ничего не уходит в сеть
- 🌓 Работает в тёмной и светлой темах Obsidian
- 🗂️ Учёт по vault'ам раздельный — у каждого хранилища своя статистика
- 🪶 Минимум кода и зависимостей: TypeScript + esbuild, без внешних библиотек

## 📦 Установка

### Вручную

1. Скачайте три файла: `main.js`, `manifest.json`, `styles.css`
2. Создайте папку `vaultclock` в `<Ваш Vault>/.obsidian/plugins/`
3. Положите все три файла в эту папку
4. Откройте **Настройки → Сторонние плагины** и включите **VaultClock**

### Из исходников

```bash
git clone https://github.com/RamenOfficialGovPatsy/VaultClock
cd VaultClock
npm install
npm run build
```

Затем скопируйте `main.js`, `manifest.json` и `styles.css` в `<Ваш Vault>/.obsidian/plugins/vaultclock/` и включите плагин в настройках.

> **Примечание:** плагин пока не опубликован в каталоге community plugins Obsidian. 🕰️

<a id="how-it-works"></a>

## 🛠️ Как это работает

- Формат — `Xч Yм`. Если значение меньше минуты, показывается `< 1м`.
- Тик каждые 30 секунд прибавляет 30 секунд к счётчику текущей даты.
- При сворачивании окна (`visibilitychange`), закрытии (`beforeunload`) и выгрузке плагина (`onunload`) добирается остаток с последнего тика и сохраняется `data.json`.
- В `data.json` хранятся только дневные суммы: `{ "days": { "YYYY-MM-DD": seconds } }`.
- При старте плагина отсчёт начинается с текущего момента — прошедшее «пока плагин не работал» время не добавляется (защита от двойного счёта после краша).
- Файл `data.json` лежит в `.obsidian/plugins/vaultclock/` конкретного хранилища, поэтому статистика по каждому хранилищу независима.

Плагин использует CSS-переменные Obsidian (`--background-secondary`, `--text-normal`, `--text-muted`), поэтому автоматически подстраивается под тему. Отдельных настроек цвета нет — и не нужно.

> **Примечание:** плагин намеренно не имеет вкладки настроек. Всё работает «из коробки».
